System Architecture
🔀
API Gateway
:8000
Single entry point for all client requests. Routes to services, hosts GraphQL.
●
👥
User Service
:8001
User registration, login, and profile management.
●
🎥
Movie Service
:8002
Movie catalog with CRUD operations.
●
🎟️
Booking Service
:8003
Core business service. Synchronously validates users, movies, seats then publishes async events.
●
🪑
Show/Seat Service
:8004
Shows, theatres, and seat management with LOCK mechanism.
●
🔔
Notification Service
:8005
Async consumer. Reads from RabbitMQ and generates booking notifications.
●
SYNCHRONOUS
Booking Service → User Service
Booking Service → Movie Service
Booking Service → Show/Seat Service (verify + lock + book)
HTTP / REST
ASYNCHRONOUS
Booking Service → RabbitMQ → Notification Service
RabbitMQ (AMQP)
